# AI Interview Studio 🎓

An advanced, AI-powered platform for technical mock interviews, providing real-time proctoring and personalized analytical feedback.

---

## 🚀 Quick Start - Running on VS Code

Running the entire platform is now easier than ever. One command starts the server, the database, and the frontend interactive dashboard.

### 1. Prerequisite
Ensure you have [Node.js](https://nodejs.org/) installed on your computer.

### 2. Setup
Open your terminal in the root directory (where this README is located) and run:
```bash
npm install
```

### 3. Execution
To launch the **AI Studio Platform**, run:
```bash
npm start
```
This single command will:
1.  Initialize the **Backend API and Database** (Port 3000)
2.  Launch the **Frontend Dashboard** (Port 5173)

### 4. Open in Browser
Once the terminal shows "Vite started," press **Ctrl + Click** on the link below in your VS Code terminal:
👉 **[http://localhost:5173](http://localhost:5173)**

## 🛠️ Project Structure
- **/frontend**: React + Vite user interface and dashboard.
- **/backend (root)**: Node + Express server logic and SQLite database.
- **server.js**: Main entry point for the backend logic.
- **TECH_STACK.md**: Detailed technical documentation.

## 🤖 Features
- **Adaptive Questioning**: AI changes difficulty based on your previous answers.
- **AI Proctoring**: Real-time facial monitoring and voice detection to ensure assessment integrity.
- **Chat Mentor**: Integrated AI Academic Mentor to handle syllabus doubts.
- **Golden Certificate**: Claim your professional excellence certificate upon reaching eligibility.
